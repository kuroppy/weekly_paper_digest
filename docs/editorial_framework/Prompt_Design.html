Prompt Design

Version: 1.0 Published: 2026-07-23

この文書は、Weekly Paper Digestで利用するプロンプトの設計思想をまとめたものです。

基本方針

Promptは、音声原稿を生成するための指示ではない。

Weekly Paper Digestが目指す編集方針を、AIと共有するための設計図である。

そのため、プロンプトは出力形式を指定するだけではなく、

「どのような視点で論文を読み、どのような順序で紹介するか」

という編集思想そのものを記述する。

Prompt Design

主役は論文である

Promptでは、AIが独自のテーマやストーリーを作ることを求めない。

紹介する論文や番組構成は編集者が決定し、AIはその論文が持つ面白さを引き出すことに集中する。

AIは新しいコンテンツを作るのではなく、論文の価値を伝える編集者として振る舞う。

結論ではなく、理解の順序を大切にする

研究者は、最初から結論を知って論文を読むわけではない。

問いを持ち、仮説を立て、証拠を読みながら少しずつ理解を深めていく。

Promptでは、この理解の順序を音声でも再現することを重視する。

結論を先に説明するのではなく、リスナーも研究者と同じ順番で理解できる構成を目指す。

すべてを説明しない

番組の目的は、論文を完全に理解してもらうことではない。

最も重要なのは、

「この論文を読んでみたい」

と思ってもらうことである。

そのため、論文中のすべての実験を紹介するのではなく、中心となる問いと、それを支える重要な証拠に焦点を当てる。

AIに創作をさせない

Promptでは、AIが存在しない背景や論争、比喩やストーリーを作ることを避ける。

面白さはAIが付け加えるものではなく、論文そのものが持っているものと考える。

AIの役割は、その面白さを自然な対話として伝えることである。

対話として伝える

番組は講義ではなく、研究者同士の雑談を目指している。

専門知識を前提にせず、一方で過度な一般向け解説にもならない。

研究者が論文を紹介し合うときの自然な会話を再現することを重視する。

プロンプトの改善

Promptは完成されたものではない。

実際の配信を通して振り返りを行い、改善点が見つかった場合は、プロンプトを更新するとともに、その変更理由も記録していく。

設計思想

Promptの改善は、AIの自由度を高めることではなく、編集方針をより正確に共有することを目的としている。

そのため、Versionを重ねるごとに「AIに何をさせるか」だけでなく、「AIに何をさせないか」も明確化してきた。

Weekly Paper Digestでは、制約は創造性を妨げるものではなく、編集品質を支える設計要素であると考えている。
