Curation Policy

Version: 0.0 Published: 2026-07-03

この文書は、プロジェクト開始当時（2026年5月）の論文選定方針を、当時のREADMEや初期の記録をもとに再構成したものです。

基本方針

Weekly Paper Digestでは、個々の論文を紹介することよりも、

分野の中で共有されている話題を伝えること

を重視する。

一つの論文だけを取り上げるのではなく、関連する研究をまとめて紹介することで、

「今、このテーマが注目されている。」

という分野全体の流れを伝えることを目指す。

テーマを中心に編集する

まず、毎週収集した論文から複数のテーマを抽出する。

その後、各テーマに関連する複数の論文を整理し、そのテーマを代表する論文を選ぶ。

Version 0.0では、

  • 3つのテーマを選ぶ
  • 各テーマについて3本の論文を紹介する
  • 各テーマから1本を深掘り論文として解説する

という構成を採用した。

3という数に特別な意味はなく、

配信時間とのバランスや聞きやすさを考えた結果として決定した。

深掘り論文

各テーマについては、代表となる1本を詳しく紹介する。

これは、日頃から個人的な論文理解のために利用していた「1本を深掘りする」というスタイルが非常に学習効果が高かったためである。

一方で、配信時間には限りがあるため、すべての論文を同じ深さで紹介することは行わない。

「良い論文」の考え方

Version 0.0では、論文そのもののインパクトよりも、

研究者同士の共通の話題になりやすいこと

を重視した。

そのため、

  • 一定数の研究者が関わるテーマ
  • 分野としてある程度まとまりを持っている話題
  • そのテーマを理解する入口となる論文

を優先して選定する。

分野全体を少しずつ理解する

1週間だけで分野全体を網羅することは目指さない。

毎週異なるテーマを扱うことで、

長期間聞き続けたときに、ゲノム微生物学全体を少しずつ俯瞰できるようになることを目指す。

今後の見直し

この文書はVersion 0.0であり、プロジェクト開始当時の考え方を記録したものである。

論文選定の考え方が変わった場合は、新しいVersionとして記録していく。
