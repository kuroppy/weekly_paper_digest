Editorial Framework

Version 0.0

Editorial Framework は、Weekly Paper Digest をどのような考え方で編集し、運用していくかをまとめるためのドキュメント群です。

Podcastの成果物だけでなく、論文選定やPrompt設計など、編集の考え方を整理し、必要に応じて更新していきます。

Version 0.0 は、プロジェクト開始当時の考え方を、README や初期の記録をもとに再構成したものです。

Current Framework

Editorial Framework は、編集思想を4つのレイヤーに分けて管理します。

Manifesto

Why?

このプロジェクトの目的を記録した文書。

Editorial Policy

What?

配信構成、語り方、番組として大切にする編集方針。

Curation Policy

Which?

どのような論文を選ぶのかを考えるための方針。

Prompt Design

How?

編集方針をLLMのPromptへ実装するための設計指針。

Archive

過去バージョンは必要に応じて参照できるよう、archive に保存します。
